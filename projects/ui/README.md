# @xenode/ui

A shadcn-style Angular component library: components are directives on native
elements where possible, styled exclusively with Tailwind utility classes and
shadcn-compatible CSS custom-property tokens. No component stylesheets, by
design — see the workspace root README.

Consumed from source by `projects/portfolio` via the `@xenode/ui` path
mapping. Not published to npm; `ng build @xenode/ui` exists for verifying the
library packages cleanly, not for distribution.

Run its tests with:

```bash
ng test @xenode/ui
```
