# Security

## Supported versions

Only `main`. This project is pre-release; there are no supported version lines yet.

## Reporting a vulnerability

Use GitHub's private vulnerability reporting on this repository. Expect a first
response within about a week.

## Scope

A statically prerendered site and an Angular component library. There is no
backend, no authentication, and no user data.

## Accepted findings

None currently (`npm audit` clean as of 2026-08-12). Any finding accepted
rather than fixed will be recorded here with its reasoning.
